# Support

RepoArena is an open-source alpha and does not currently include paid support or service-level
guarantees.

- Ask usage and setup questions in [GitHub Discussions](https://github.com/tugrakaymakcioglu/RepoArena/discussions).
- Report reproducible bugs with the bug report form.
- Propose scoped product improvements with the feature request form.
- Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/tugrakaymakcioglu/RepoArena/security/advisories/new).

Before opening a report, run `repoarena doctor` and remove repository source, access tokens, API
keys, credential paths, and other sensitive information from logs.
